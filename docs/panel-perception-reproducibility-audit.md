# 消防面板感知：复现证据与仿真验收边界

> 2026-09-24，仅审查本仓库归档与本机 WSL 环境。没有连接或改变工控机、摄像头、底盘和机械臂，也没有对真实图像做识别测试。

## 结论

当前双目链能够在**理想彩色按钮和 ArUco 面板**上估计按钮三维位置，并把位置放进同一张图优化的三维占据图；它尚不能证明识别真实消防主机的文字、指示灯状态或操作结果。先补齐可复跑的面板图像与标注，再比较归档模型和新方案，才有论文意义上的感知指标。

| 项目 | 论文叙述 | 当前归档证据 | 复现状态 |
|---|---|---|---|
| OCR 数据 | 采集 650 张，筛选 500 张，训练/验证/测试为 6:3:1 | `reference/industrial_pc_2026-09-22` 下未检出 `.jpg/.jpeg/.png/.bmp`、`train.txt`、`test.txt`、`Label.txt`、`rec_gt.txt` | 无法重做训练、盲测或复核论文指标；“未归档”不等于原机不存在 |
| OCR 模型 | 微调 PP-OCRv5 mobile det/rec | `fire_panel_rec/models` 有 PP-OCRv3 det/rec 和 v2 cls 的 `.pdmodel`、`.pdiparams`、字符表；`ocr_rec_test.launch.py` 也指向 v3 | 可以作为历史基线候选；不能称为论文的 v5 微调模型 |

## 需要先验证的源码风险

1. `parse_led_region.cpp` 第 43、72 行先把 BGR 转 HSV 并把 HSV ROI 传给 `analyzeLED`；第 318–324 行却用 `COLOR_BGR2GRAY` 对这块 HSV 数据计算“平均亮度”。颜色通道解释不一致，亮灭门槛可能失真。应在隔离副本上用已标注的亮/灭样本复现，再修正为从原 BGR 灯区或 HSV 的 V 通道求亮度；归档原件保持只读。
2. 第 159–173 行多帧规则是“只要任一帧判亮就判亮”，不是多数票。反光、误检在长窗口中可能被放大。需要固定采样窗口和帧级真值，比较误报、漏报与闪烁灯响应。
3. `single_shot_rec_node.cpp` 的服务链依赖相机采图服务；仿真若只想评价推理算法，应提供离线图像输入，避免把真实相机、曝光控制和视觉算法问题混在一轮实验中。

这些是**静态审查风险**，不是已经运行原始 C++ 节点后测得的缺陷率。本机 WSL 的 OpenCV 4.5.4 可用；本次检查中未安装 Python `openvino`、`paddleocr`、`pip` 和 `pytesseract`。归档的 C++ 工程要求 OpenVINO、gflags、OpenCV 和若干 ROS 包，不能仅凭模型文件断言已能在当前 WSL 运行。

## 下一项仿真实验的验收门槛

1. **数据与真值**：保留原始左右相机图、时间戳、CameraInfo、曝光、面板/文字框/LED 灯框及状态、按钮 3D 真值和遮挡标记。真实图像若后来取得，应单独许可、去敏并按采集场景划分训练与测试，避免同一连续视频的相邻帧泄漏。没有真实图像时，可生成带中文文字、红黄绿/熄灭灯、光照/视角/反光/遮挡变化的合成面板，但只报告合成域结果。
2. **先做离线感知基线**：在同一批图像上比较归档 v3 模型与可运行的官方/新模型，记录文字检测召回、字符/词正确率、LED 混淆矩阵和未知状态比例；对 OCR 输出框而非真值框进行灯位关联，以免绕开真实误差链。运行依赖、模型版本和数据划分须固定并记录。
3. **再接实时双目图**：每个观测含图像时间戳、相机光学坐标、文字/灯/按钮类别、置信度、深度有效像素数和三维位置；通过既有 `graph_map` 投影对齐三维占据图。灯态是随时间变化的属性，不能当作静态地图障碍；旧状态要过期，遮挡/低置信度时标为未知。验证地图更新后语义位置的一致性，不只检查当前帧最近体素。
4. **决策前安全门**：只有稳定识别的面板身份、目标按钮、状态变化及新鲜的地图/定位同时满足门槛，才产生“可操作”建议；仿真默认不向实机发动作。评估误按风险、障碍与定位失效下的拒绝动作，并记录从采图到状态输出的延迟分布及 CPU/内存负载。

### 最小可证伪场景

| 场景 | 应有证据 |
|---|---|
| 固定正视面板，红灯亮/灭切换 | OCR 文本框、灯态、图地图中的对应地标与时序日志；灭灯后旧红态确实过期 |
| 倾斜或弱光面板 | 各阶段正确率和置信度下降情况；不满足门槛时输出未知 |
| 反光导致单帧误亮 | 单帧与多帧策略的误报对照 |
| 文字或灯被遮挡 | 不输出凭空确定的状态或按钮三维坐标；控制链保持停止 |
| 图地图修正后重访 | 旧观测与新观测坐标差、地标重投影结果和 3D 占据一致性 |

**研究结论边界**：归档缺失的真实样本、v5 微调权重和采集协议不能由合成图补出；现有颜色按钮实验的毫米/厘米误差只说明受控几何定位，不说明真实 OCR、LED 判态或完整消防处置可用。

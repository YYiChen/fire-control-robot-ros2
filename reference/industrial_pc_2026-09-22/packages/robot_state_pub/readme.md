## robot_state_pub 功能包说明

这是一个用于发布机器人整体状态信息的ROS 2功能包，负责收集和发布机器人的综合状态。

### 功能概述

该功能包提供了一个名为 robot_state_pub 的节点，用于定期发布机器人的综合状态信息。它通过订阅任务状态信息并整合其他机器人状态数据，形成完整的机器人状态报告。

### 主要功能

1. **机器人状态发布**
   - 定期发布机器人的综合状态信息
   - 整合多个子系统的状态数据

2. **任务状态监控**
   - 订阅任务管理器发布的任务状态信息
   - 将任务状态整合到机器人整体状态中

3. **状态数据管理**
   - 管理电池电量等机器人基础状态信息
   - 提供统一的状态信息发布接口

### ROS 2 接口

#### 消息 (Messages)

##### 发布的消息
- `/fia_robot/status` common_interfaces/msg/RobotStatus
  - 发布机器人的综合状态信息
  - 包含任务状态和其他机器人状态数据

##### 订阅的消息
- `/task/status` common_interfaces/msg/TaskStatus 
  - 订阅任务管理器发布的任务状态信息
  - 用于更新机器人状态中的任务相关信息

#### 定时器
- 每秒触发一次状态发布定时器
- 定期更新并发布机器人状态信息



### 使用说明

1. **运行节点**
   ```bash
   ros2 run robot_state_pub robot_state_pub
   ```

2. **查看状态信息**
   ```bash
   # 订阅机器人状态信息
   ros2 topic echo /fia_robot/status
   ```

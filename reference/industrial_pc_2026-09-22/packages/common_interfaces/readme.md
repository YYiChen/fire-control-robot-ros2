# 包含消息接口

- TaskStatus.msg
定义任务状态信息，包括主任务类型（如导航、日常值守、报警处理）、子任务类型、任务状态（如待处理、处理中、成功、失败等）、任务ID、位置和错误信息等字段，用于描述机器人当前执行任务的状态。

- LiftStatus.msg
描述升降设备的状态信息，包括各个电机的当前位置、设备ID、运动状态和运动方向，用于监控升降设备的实时状态。

- ArmTaskType.msg
定义机械臂任务类型，包括常规操作、日常值守、报警处理等分类及其具体子任务（如回原位、AR码定位、拍摄等），用于指定机械臂需要执行的具体任务。

- LEDStatus.msg
表示LED指示灯的状态，包括指示灯名称和状态（如关闭、红、绿、黄、未知），用于监控设备上各指示灯的当前状态。

- LiftQuery.msg
用于查询升降设备的信息，包括是否请求位置反馈、查询指定电机的位置以及是否请求设备ID，作为控制和查询升降设备的指令。

- RobotStatus.msg
描述机器人整体状态，包括电池电量和任务状态（嵌套了TaskStatus消息），用于监控机器人的基本运行状态。

- ScreenInfo.msg
描述消防主机屏幕信息，包括当前页面、主机型号、报警详情（如首次火警信息、当前激活火警信息）和各类状态标志（监管、启动、反馈、延时、故障、屏蔽等），用于反映消防主机的显示内容和报警状态。

- PanelRegion.msg
定义控制面板区域的标识符，包括屏幕、LED、按钮等区域及其细分（如数字按钮、功能按钮），用于标识机器人需要交互的控制面板上的具体区域。

# 包含服务接口

- TriggerImageCapture.srv
触发图像捕获的服务，客户端可以请求获取矫正或未矫正的图像，服务端返回捕获的图像数据和操作结果。

- ControlGripper.srv
控制机械臂夹爪的服务，支持打开/关闭夹爪操作，也可以通过命名位置或关节位置精确控制夹爪，服务端返回操作结果和状态信息。

- GetCameraInfo.srv
获取相机信息的服务，客户端请求后服务端返回相机的标定信息（CameraInfo消息）和操作结果。

- GetPanelInfo.srv
获取控制面板信息的服务，客户端指定面板型号和区域，服务端返回屏幕信息和指示灯状态数组。

- GetPanelRegionPose.srv
获取面板区域位姿的服务，客户端指定面板区域，服务端返回该区域在空间中的位姿信息（PoseStamped）。

- LiftCommand.srv
控制升降设备的服务，支持多种操作类型（停止、上升、下降、复位、设定高度、设置设备ID、步进等），服务端返回操作结果和状态信息。

- RobotCommand.srv
向机器人发送指令的服务，支持各种操作命令（如确认报警、记录日志等），可指定目标区域和附加参数，服务端返回执行结果和详细信息。

- SetCameraParams.srv
设置相机参数的服务，支持配置自动/手动增益和曝光参数，包括上下限设置，服务端返回参数设置结果和状态信息。

# 包含动作接口

- TaskJs.action
执行任务的动作接口，客户端通过task_cfg字符串传递任务配置信息，动作执行过程中可以反馈进度百分比，执行完成后返回结果码。

- ExecuteArmTask.action执行机械臂任务的动作接口，客户端可以指定任务类型、路径点、关节名称和目标角度，动作执行过程中反馈当前路径点索引和完成百分比，执行完成后返回成功状态和消息。
